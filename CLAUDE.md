# Claude repository instructions

Before working on this repository, read and follow:

1. `AGENTS.md` — the canonical repository workflow and operating rules.
2. `SITE-DESIGN-PRINCIPLES.md` — the canonical visual, writing and technical design system.

Both documents apply to every folder and page. If this file is shorter than `AGENTS.md`, that is intentional: do not duplicate or reinterpret the canonical rules.

## Non-negotiable summary

- Preserve the four public routes: root portfolio, résumé, checkout dashboard and promo-code case study.
- Keep the site static, portable and compatible with GitHub Pages.
- Use the existing Geist font, black visual system and hot-coral accent.
- Prefer subtraction, evidence and working examples over decorative presentation.
- Use only factual, supportable claims; never invent metrics or outcomes.
- Keep large media and data outside HTML and use relative paths.
- Maintain accessibility, responsive behaviour and reduced-motion support.
- Keep the promo-code page aligned with the root portfolio design.
- Review locally before publishing.
- Never push or deploy without Vipin's fresh explicit approval, and never force-push.

When uncertain, make the smallest useful change and preserve the existing evidence.
