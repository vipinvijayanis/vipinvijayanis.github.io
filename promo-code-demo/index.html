Live customer feature · Afterpay

Promo codes,
inside checkout.

I designed, built and launched promo-code redemption directly in checkout, using AI agents and checkout-engineer review.

01 · The problem

The offer broke the flow.

Customers had to leave checkout, open the Afterpay app, redeem the offer and then return to the merchant to pay.

BeforeLeave checkout → redeem → return
NeededEnter code → see discount → pay

02 · The solution

Redeem without leaving checkout.

The feature validates the code against the campaign and customer, then applies the discount immediately in the order summary.

03 · The impact

Live at customer scale.

1M+Customers who used the feature
5+Marketing campaigns using the live feature
$10M+Incremental purchase volume generated

04 · How I built it

No allocated engineering capacity. So I became the builder.

AI agents accelerated planning and implementation. I remained accountable for the product decisions, testing and release; experienced checkout engineers reviewed the direction and each increment.

  1. Plan

    Map the work. One agent translated the idea into surfaces, dependencies, risks and a delivery sequence.

  2. Challenge

    Test the assumptions. A second agent looked for missing cases and simpler paths before implementation.

  3. Ship

    Keep changes reviewable. I built, tested and reviewed the feature with checkout engineers one increment at a time.

05 · What I learned

What I underestimated.

  • Local testing

    Testing locally was more complex than I expected. I had to mock each visibility, success and failure scenario and verify it in the checkout harness.

  • PR review

    Agent build time fell, but manual PR review became the bottleneck. Delivery still took longer than I had anticipated.

  • Visual fidelity

    I overestimated how close an agent would get from a supplied design. Pixel-perfect implementation required many rounds of comparison, feedback and iteration.
